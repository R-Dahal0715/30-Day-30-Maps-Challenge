# Day 1: Creating a Provincial Map of Nepal in QGIS

## What I did?
Opened and explored QGIS.
Added Nepal’s provincial boundary layer.
Inspected the attribute table.
Checked geometry type and CRS.
Styled provinces using categorized colors.
Added province labels.
Created a print layout.
Exported the map.

## Skills learned
Polygon geometry
Attribute tables
Layer styling
Categorized symbology
Labels
Map frame
Legend and scale bar
Map export

### Reflection
Day 1 introduced me to the basic workflow of GIS: loading spatial data, inspecting attributes, styling features, and producing a readable map. I learned that a polygon layer contains both geometry and descriptive attributes, and that cartographic design is important for communicating spatial information clearly.
